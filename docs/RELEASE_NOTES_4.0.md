# Nexus Sushi Bar 4.0.0

## Maestria marinha

A versão 4.0 transforma a coleção de peixes em uma trilha de progressão de longo prazo.

- Cada espécie possui progresso individual.
- Marcos por espécie: Descoberto (1 captura), Familiar (5 capturas) e Especialista (15 capturas).
- Recompensas únicas e automáticas: 5, 15 e 40 moedas por marco.
- O diário mostra capturas, classificação atual, barra de progresso e próximo marco.
- A maestria é calculada por espécie e não depende de sequência diária.
- Save schema 14 preserva os dados existentes e registra recompensas já recebidas.

## Base do jogo mantida

- Cinco biomas e doze espécies.
- Desafios diários e semanais.
- Marcos de atividade acumulativos.
- Eventos especiais e três temas de restaurante.
- Interface em português, inglês e espanhol.

## Qualidade e validação

A suíte automatizada deve passar integralmente no GitHub Actions. A validação visual e de jogabilidade em dispositivos reais continua sendo uma etapa manual necessária antes de considerar a experiência integralmente homologada.

## Tecnologia

HTML5 Canvas, CSS, JavaScript ES modules, LocalStorage e GitHub Pages.
