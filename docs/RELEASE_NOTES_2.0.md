# Nexus Sushi Bar 2.0.0

## Core loop

Explore one of three underwater biomes, catch fish with rarity-weighted spawning, manage oxygen and catch quality, return to the surface and transfer ingredients into the restaurant.

At night, serve a customer queue using multi-stage sushi and tea recipes. Each recipe requires the correct kitchen stations. Successful service earns revenue, tips and reputation; walkouts reduce reputation and satisfaction.

## Progression

- Five fishing ranks and equipment tiers.
- Four equipment specializations: Balanced, Endurance, Swift and Cargo.
- Restaurant levels unlock additional guests and specialty menu items.
- Décor upgrades improve customer patience.
- VIP nights and the weekly Festival of Lanterns add special guests and rewards.

## Menu

The menu includes the original nigiri and teas, specialty dishes made from rarer fish, Genmaicha and Yuzu. Ingredient stock is consumed only after a complete recipe.

## Accessibility and persistence

- First-dive tutorial.
- Optional synthesized sound effects.
- Persistent reduced-motion preference.
- Versioned save schema 9 with safe normalization of older and malformed saves.

## Validation

Automated CI checks JavaScript syntax, gameplay logic, recipe stage durations, station references, progression, economy rules and save normalization.

## Known release gate

The project has not yet passed a hands-on acceptance run on real desktop and iPhone/iPad browsers. Confirm the GitHub Pages deployment, touch controls, audio behavior, responsive layouts and the complete day/night loop before treating the build as fully device-verified.
